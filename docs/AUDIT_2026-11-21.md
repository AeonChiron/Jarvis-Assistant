# Code and usability audit, 2026-11-21

Audited commit: `8506a94`. 18 findings: 6 high, 10 medium, 2 low. Each finding gets a regression test first
(sidecar tests in `showcase/tauri/sidecar/test/audit*.test.mjs`), then the fix. Status is kept on the `Status:` line.

## High

### F01 Model names injected as HTML; open bridge to permission changes
`showcase/panel/home.js` ~L80-87 put `model.name` into `innerHTML`, so a model id like `<svg onload=...>` from a
connected local/custom model server ran script. Tauri has `withGlobalTauri` and `csp: null`; `sidecar_send`
(`src-tauri/src/main.rs` ~L330) forwards arbitrary JSON and the sidecar accepts menu messages that toggle action
permissions and skipped confirmations.
Fix: text nodes for model names/versions (and other innerHTML uses), a restrictive CSP where inline handlers allow
it, permission-changing messages only from the panel/home window with a valid schema.
Status: fixed (test: auditsafety F01 + browser check under the CSP). Model names/version are text nodes; CSP set in tauri.conf.json, the 3 inline scripts moved to files; sidecar_send stamps the sending window, the sidecar drops permission/key/model-server messages not from panel/home/onboarding or in the wrong shape (permissionMessageOk).

### F02 Secret paths matched case-sensitively
`sidecar/safety.mjs` L15-26: `.GG/AUTH.JSON` passed `read_file` on Windows; canonical comparison kept the original
spelling. Fix: case-insensitive on win32/darwin, check the canonical target path.
Status: fixed (test: auditsafety F02). Secret/private/no-write rules ignore case on Windows and macOS.

### F03 search_files reads protected children
`sidecar/tools.mjs` ~L927-935 checked only the root; rg/grep then returned contents of e.g. `project/private.pem`.
Fix: read policy per file (exclusions + result filtering) for ripgrep and the grep fallback.
Status: fixed (test: audittools F03). rg/grep skip key files and folders, and every result file passes checkRead (filterSearchOutput). Only grep is installed on the dev PC; the rg branch uses the same filter.

### F04 `open` launches executables
`safety.mjs` L402-427 denylist missed `.lnk .hta .msi .vbs .scr`...; `tools.mjs` L974-997 launched via Start-Process
without the master action switch. Fix: allowlist of document types; other files are revealed in Explorer.
Status: fixed (test: auditsafety F04). Files open only when they are documents/media/web pages (allowlist); anything else comes back block+reveal and is shown in its folder. Apps by name and links unchanged (no master switch: an installed app or a link runs no payload).

### F05 Abort ignored by run_command and hands
`tools.mjs` L25-34 / L955-965 / L280-300. Fix: pass the signal, kill the owned process tree (taskkill /PID /T),
check cancellation after approval waits.
Status: fixed (test: audittools F05, 400 ms marker aborted at 100 ms, plus a control run). run() kills the owned process tree (taskkill /PID /T, POSIX process group); run_command and act_in_app check Stop after the Allow wait.

### F06 Return key / coordinate clicks bypass risky-action confirmation; skipAllow suppresses risky asks
`tools.mjs` L831-854 / L326-331, `hands-win/src/act.rs` L834-853. Fix: approval for key activation / coordinate
clicks when the consequence is unknown or risky; risky approvals independent of skipAllow.
Status: fixed (test: audittools F06). Return/Enter/Space and click_at ask first unless Return just submits a search box filled in the same plan; risky asks ignore Skip Allow; hands-win refuses those steps without confirmed (verified by the cloud cargo build).
